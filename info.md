# Allanic Nature Theme

Palette nature sobre pour Home Assistant, pensée pour tablettes Kindle Fire en wall display permanent.

**Variants livrés :**
- `allanic_nature` — dark (défaut)
- `allanic_nature_light` — light (fallback jour)

**Activation :** Profil → Thème → `allanic_nature`.

**Pré-requis** dans `configuration.yaml` :
```yaml
frontend:
  themes: !include_dir_merge_named themes
```

Voir [README](https://github.com/maximeallanic/ha-allanic-nature-theme) pour détails complets.
